# ATO-hub — atualizações

Canal oficial de atualizações do **ATO-hub**, produto da **Minerva Engenharia**.

Cada versão publicada aqui traz dois arquivos:

- `ATO-hub_Setup_<versão>.exe` — o instalador para Windows;
- `atohub-atualizacao.json` — o manifesto da versão, **assinado com a chave da Minerva**, com o tamanho e a impressão digital (SHA-256) do instalador.

As versões ficam guardadas aqui, mas **um cliente só recebe a atualização quando a Minerva a libera** (pasta liberacoes). O app **só instala se a assinatura do manifesto e o SHA-256 do instalador conferirem**. O uso do sistema depende da licença emitida pela Minerva para cada cliente.
